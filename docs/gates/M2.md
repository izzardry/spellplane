## Gate scenario (`tests/e2e/m2.gate.spec.ts`)

Two pages, Ann and Ben, take part (`?transport=local`, `?profile=a` and `?profile=b`, fixture card and MTGJSON data, `?faces=placeholder`). The scenario:
- **M19 booster draft, three packs each.** Every pick is made with the arrow keys and Enter.
- **Building.** Each player builds a 40-card deck: 23 spells from the list view and 17 basics from the dispenser, including a printing choice. The builder table is sorted by colour, mana value and type with keys 1–3, and the stats readout is checked at 40 cards and 17 lands.
- **Game one.** Both press Ready and play a short game: shuffle, draw seven, play a land. Both pages end on the same state hash.
- **Game two.** "Next game" is confirmed in the prompt, a sideboard card is swapped in the list view, and game two starts.
- **Sealed and Rochester.** A sealed start with six packs each follows, then a two-seat Rochester draft of one pack each, with snake order and the rotating opener checked.
- **Leak scan** of the draft. Each seat may know only the packs it held at its turn, plus what the other seat passed on. Every pack hand-over is checked. Nothing leaked.

Every step uses the UI. No step fell back to the debug hook, and `artifacts/gate/M2-*.json` lists no failures or gaps.

## Open items and residual risks (please review)

- **Grid draft deal.** M2-P3 deals each grid from its own booster: nine cards are shown, and the other six are never in play. The other reading of "18 grids of nine face-up cards from shuffled packs" pools the boosters and deals them into grids. This needs the owner's decision.
- **Pick timer** is now offered only for pass drafts (booster, Pick-Two, Two-Headed Giant draft).
- **Winston dealer.** No audit replays the Winston or Grid pack records yet, so a modified dealer client could choose its seeded card ids.
- **Unused pack-seed rounds** (M2-P7 review). A client that lost its nonce closes its pack round unused. Peers cannot tell this apart from a client re-rolling a pack it disliked. A public count of unused rounds per seat would let the audit flag it.
- **"New draft?" passes on silence** (M2-P7 review). Following DESIGN's rule that silence counts as OK, it passes after 5 s of silence and clears every player's private pool. Only decks saved to the library survive. Consider explicit OKs for this one round.
- **A host-owned open randomness round can stall a stage step** (M2-P7 review). It is transient in normal play, and it can stick only if the waiting seat is away.
- **Draft → lobby** is allowed to the host without confirmation, which is not an edge in DESIGN; no UI uses it. `lobbySet` uses the lowest seat as host, while the evening uses the acting host.
- **Pass-draft driver and abandoned history** (found by the review fix agent). If the room's history splits and falls back to the sequencer's version, the pass driver may already have pooled a pick and dropped its copy of a pack based on the abandoned version. The next player then waits for that pack forever. The engine allows such splits, for example when the sequencer is cut off. A real reload cannot cause one, because each page load gets a new transport id. A stalled pass is possible, and it may briefly show the next player a pick from the abandoned history (unconfirmed). Planned follow-up: the driver acts only on confirmed history.
- `src/session/net.ts` `draftView()` is unused.

## CI failures found after the merge

GitHub Actions (Linux, software rendering) failed 2–4 browser tests per run on `m2`, a different set each time. Locally all 458 passed. Fixed in `78d0c57`, with no retries and no raised timeouts:
- **Real bug, `src/net/engine.ts`.** Two pages could deadlock, so that nothing was sequenced again. This happened when one page sequenced its first action before the pages met, and the other then took over as sequencer at seq 1. Its fork check went out as a snapshot read, and only an `overlap` answer completed the check. The new regression test in `tests/sim/net/protocol.test.ts` failed 4 of 60 runs with real crypto before the fix and 0 of 60 after.
- **Stack-lane and marker specs.** A legitimate timer pass by the other seat could land between the gesture and the assertion. The specs now read the log without timer passes and use timers that fit slow runners.
- **Builder sorting spec.** It ran out of its 60 s on a slow runner (58 separate attribute reads). The labels are now read in one call, and the test is split in two.
- **Evening spec.** It read the pool before the sequencer had applied the pick; it now waits for the pick to land.

Each touched spec passed `--repeat-each=20`, and the full `pnpm e2e` passed 460 of 460.

## Infrastructure decisions made during M2

- **Playwright guard** (details in `docs/DECISIONS.md`):
  - at most two runs per machine and one per worktree. The limit was raised to four on the owner's request, then put back after macOS killed every application for lack of memory;
  - no run starts below 25% free memory;
  - it waits while the load average is above 3 × CPUs, and aborts (exit 5) if it stays above 8 × CPUs;
  - it counts a prompt process only while that process has a window on screen.
- **Vitest** is capped at 4 workers locally.
- **Workflow prompts** say that a relayed user message is a status question, and they can carry a machine note. Workflow arguments are kept in `spellplane-wt/_args/`.
- **Both machine crashes** so far were macOS watchdog panics under extreme load. One stretch of overload came from failing directory services ("No user exists for uid 501"); it also broke git over SSH for a while.
